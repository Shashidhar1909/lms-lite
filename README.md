# LMS-Lite

A lightweight Learning Management System (MERN Stack).

## Tech Stack
- **Frontend**: React, Tailwind CSS, Vite
- **Backend**: Node.js, Express, MongoDB

## Features
- **Admin**: User management, Course management, Analytics.
- **Instructor**: Course content creation, Student tracking.
- **Student**: Course enrollment, Progress tracking.

## Getting Started

### Prerequisites
- Node.js
- MongoDB

### Installation

1. **Backend Setup**
   ```bash
   cd backend
   npm install
   # Configure .env
   npm start
   ```

2. **Frontend Setup**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
